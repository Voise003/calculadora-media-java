# 📚 Calculadora de Média Escolar em Java

## 📌 Sobre o projeto

Este é um projeto simples desenvolvido em Java com o objetivo de praticar os fundamentos da linguagem e a lógica de programação.

O programa permite que o usuário informe três notas escolares, calcula a média aritmética e determina se o aluno foi aprovado ou reprovado.

## ⚙️ Funcionalidades

- Receber três notas informadas pelo usuário.
- Calcular automaticamente a média das notas.
- Verificar se a média é maior ou igual a 7.
- Exibir o resultado de aprovação ou reprovação.
## 💻 Tecnologias utilizadas

- **Java** — linguagem de programação.
- **IntelliJ IDEA** — ambiente de desenvolvimento.
- **Git e GitHub** — versionamento e armazenamento do projeto.

## 🧠 Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos básicos da programação Java:

- Variáveis e tipos de dados (`double`).
- Entrada de dados com `Scanner`.
- Operadores aritméticos.
- Estruturas condicionais (`if` e `else`).
- Saída de dados com `System.out.println()`.

## ▶️ Exemplo de execução

```text
Digite a primeira nota:
8

Digite a segunda nota:
7

Digite a terceira nota:
9

Sua média é: 8.0
Aprovado!
```

## 🚀 Objetivo

Este projeto foi desenvolvido para fins de aprendizado, buscando fortalecer meus conhecimentos em lógica de programação e nos fundamentos da linguagem Java.

Futuramente, pretendo aprimorar o programa com novas funcionalidades, como validação de notas, cálculo de médias de vários alunos e armazenamento de resultados.
